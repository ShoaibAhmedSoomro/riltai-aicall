# Security Policy

At Social Cangaroo we look forward to working with security researchers across the world to keep Social Cangaroo and our users safe. If you have found an issue in any of our services, please reach out to us.

## Supported Versions
We always recommend using the latest versions of services to ensure you get all security updates

## Reporting a Vulnerability

If you believe you have found a security vulnerability within Social Cangaroo, please let us know right away. We'll try and fix the problem as soon as possible.

**Do not report vulnerabilities using public GitHub issues**. Instead, report the issue [here](https://github.com/ShoaibAhmedSoomro/social-cangaroo/security/advisories/new)

Once we've received your email we'll keep you updated as we fix the vulnerability.

## Thanks

Thank you for keeping Social Cangaroo and our users safe. 🙇
